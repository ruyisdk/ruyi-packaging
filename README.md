# ruyi packaging bot

Riko is **r**uy**i** pac**k**aging b**o**t.

WIP version checker and auto packaging for [packages-index](https://github.com/ruyisdk/packages-index/).

## Usage

```bash
$ python3 -m riko --help
```

## Dependencies

Cmdline tools:

+ [nvchecker](https://github.com/lilydjwg/nvchecker)(also python dependency)
+ [ruyi](https://github.com/ruyisdk/ruyi)
